MASTER SUPER STORE — FINAL PROPER V10
Owner: SHOUKAT ALI TAHIR

FINAL ARCHITECTURE
- No Login / Create Account.
- One shared shop.
- GitHub Pages frontend.
- Supabase cloud backend (same existing project used by Finance Assistant).
- Separate cloud tables for Products, Transactions, Customers and Suppliers.
- Realtime cloud listener for second phone / PC updates.
- LocalStorage remains an offline/fallback copy.

IMPORTANT
Cloud tables have already been created for this store.
No Firebase setup is required.
No firebase-config values are required.

SYNC STATUS
Cloud Live    = connected and realtime listening.
Cloud Saved   = latest change saved online.
Cloud Updated = another device's change was received.
Device Saved  = change is safe on this device, but internet/cloud is unavailable.
