MASTER SUPER STORE — FINAL BACKEND EDITION

This edition DOES NOT use Supabase.

Backend:
- Node.js + Express
- SQLite database (auto-created in /data/master-super-store.db)
- Passwords hashed with bcrypt
- Server-side login sessions stored in SQLite
- Every account has its own profile and its own store_data row
- Returning users log in with the same email/password and see their own profile/shop/data
- Account owner name + email appear in the top header after login
- Shop name is stored per account and can be changed in Settings
- New account logs in immediately; no email confirmation is required

Run locally:
1. Install Node.js 20+
2. Open this folder in terminal
3. npm install
4. Copy .env.example to .env and set a strong SESSION_SECRET
5. npm start
6. Open http://localhost:3000

IMPORTANT:
GitHub Pages cannot run server.js or SQLite. This full-stack version must be deployed on a Node.js host such as Render, Railway, VPS, or similar persistent server hosting.
For SQLite production hosting, keep the /data folder on persistent disk/storage.

Files:
index.html
style.css
app.js
server.js
package.json
.env.example
.gitignore

Database tables:
users      -> owner name, shop name, email, password hash
store_data -> one private JSON store database per user
sessions   -> login sessions (created by connect-sqlite3)

Security:
- Password hashes only; plain passwords are never stored
- HttpOnly SameSite session cookie
- Auth rate limiting
- Helmet security headers
- User store endpoints require authenticated session


RENDER DEPLOYMENT — FINAL

This package is ready for Render.

1. Upload ALL files from this folder to your GitHub repository root.
2. Make sure these files are present:
   - index.html
   - style.css
   - app.js
   - server.js
   - package.json
   - render.yaml
3. Go to Render.com and sign in with GitHub.
4. Click New + -> Blueprint.
5. Select the GitHub repository containing this project.
6. Render will detect render.yaml automatically.
7. Click Apply.
8. Wait for build and deployment to finish.
9. Open the URL Render gives you, for example:
   https://master-super-store-assistant.onrender.com
10. Test:
   - Create Account
   - Log Out
   - Sign In again with same account
   - Confirm same profile/store data returns
   - Create another account and confirm its data is separate

IMPORTANT:
- Do NOT use the GitHub Pages URL for this backend version.
- Use the Render URL only.
- Persistent SQLite data is stored on the Render disk mounted at /var/data.
- SESSION_SECRET is auto-generated by Render using render.yaml.
- Free Render services may sleep when inactive, so first load after inactivity can take some time.
